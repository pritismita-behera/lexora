# 📚 Lexora E-Library

> **Learn • Read • Grow**

Lexora E-Library is a modern digital library platform that helps users
discover, read, borrow, and manage books and digital learning resources.

## ✨ Features

-   🔐 User registration and login
-   🔎 Search and browse books
-   📖 Read and borrow books
-   🔖 My Library
-   📅 Book reservations
-   💰 Fine management
-   🛠️ Admin dashboard
-   📚 Book, category, and user management
-   📥 Digital resource access

## 🛠️ Tech Stack

-   **Frontend:** React
-   **Backend:** FastAPI
-   **Database:** PostgreSQL

## 📂 Project Structure

``` text
lexora-e-library/
├── frontend/       # React application
├── backend/        # FastAPI application
├── database/       # PostgreSQL database/schema
└── README.md
```

## 🚀 Getting Started

### Clone the repository

``` bash
git clone https://github.com/your-username/lexora-e-library.git
cd lexora-e-library
```

### Run the frontend

``` bash
cd frontend
npm install
npm run dev
```

### Run the backend

``` bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

> Configure your PostgreSQL connection and environment variables before
> running the application.
